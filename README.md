# Sim Life · 城市人生

一款用 **Godot 4.7.2** 做的第一人称开放城市人生模拟游戏。
灵感来自 Garry's Mod 的 DarkRP 服务器：选职业、赚钱、买房、买车、装修、加入帮派。

程序化生成的城市；可选的 [Quaternius《Downtown City MegaKit》](https://quaternius.com) 与人形角色包提供 CC0 模型。干净克隆缺少这些包时，使用仓库自带的原创低模模块与带走路/跑步/待机动画的人物替代；室内家具、道路与载具由代码生成。

---

## 快速开始

**从源码运行：** 用官方 Godot 4.7.2 打开 `project.godot` 后按 F5（主场景为 `scenes/main.tscn`）。Windows 开发环境也可执行 `./tools/godot.ps1`，或设置 `SIM_LIFE_GODOT` 指向自己的便携版。仓库不包含打包成品。

**用编辑器打开：** 用 Godot 4.7.2 打开本目录的 `project.godot`。

## 玩法

### 1. 平板电脑（Tab）

游戏里所有"菜单"都在玩家随身携带的平板上，共 9 页：

- **城市地图** — 俯视图，标出全部地点、待售房产、任务目标、自己的车和当前位置
- **职业中心** — 申请 / 切换职业
- **任务** — 接取与追踪当前职业的任务
- **房产** — 购买房屋、进入装修
- **店铺** — 租赁餐厅 / 便利店的使用权
- **车辆** — 车行购车、引擎与轮胎改装、喷漆
- **武器** — 资格测验、购买、装备与弹匣状态
- **帮派** — 加入帮派、接帮派活
- **档案** — 生涯统计与操作说明

### 2. 职业与赚钱

| 职业 | 赚钱方式 | 备注 |
| --- | --- | --- |
| 警察 | 巡逻打卡、追捕通缉犯 | 在警局门口可查看勤务 |
| 消防员 | 赶往火场，按住 `E` 灭火 | 消防站 |
| 医生 | 前往伤员位置，按住 `E` 急救 | 圣心医院 |
| 厨师 | **租下日落餐厅后**，在门口开门营业 | 需先租店铺 |
| 便利店老板 | **租下便利店后**，在门口开门营业 | 需先租店铺 |
| 帮派成员 | 抢地盘、走私送货、洗劫便利店 | 报酬高，会涨通缉度 |

- 每完成一个任务**立即结算现金**。
- 在职期间每天 0 点还会自动到账一笔日薪。
- 通缉度（0–5）会随时间缓慢衰减，帮派任务会明显提升它。
- **快递员：** 在职业中心申请，到南城邮局按住 `E` 取件，再到收件点交付，结算 $420。可以步行或驾车；任务进度可以存档。
- 切换职业会取消不兼容的在途任务；店铺租期按含当天的 7 天计算，到期后不能继续营业。

### 3. 房产与装修

- 8 套可购买房产，价格 $9,800 – $34,000，包含新增的南城住宅区。
- 买下后走到门口按 `B` 进入**装修模式**：左侧是家具目录（12 种），右侧是已摆放列表。
- 家具会放在你正前方，被占用时自动向旁边顺延。回收返还 60% 购价。
- 房子是**中空可进入**的，墙、屋顶、室内灯都是真实几何体。
- 需要在自家屋内装修；没有可用空位、越界或重叠时不会扣款。不同房产的家具会一起保存和显示。自家门口可以休息恢复状态。

### 4. 车辆与改装

- 车行有 5 款车：小踏板、家用轿车、厢式货车、越野皮卡、GT 跑车。
- 买车后车会停在**公共停车场**（地图上有标注），走过去按 `E` 上车。
- 平板「车辆」页可以对每辆车升级**引擎**（三阶）和**轮胎/悬挂**（三阶），以及 7 种喷漆。
- 改装会实时影响极速、加速和抓地力。

### 5. 帮派

- 在平板「帮派」页加入毒蛇帮或灰烬会，自动转职为帮派成员。
- 三种帮派任务：**抢占地盘**（驻守 8 秒）、**走私送货**、**洗劫便利店**（通缉度 +2）。

### 6. 昼夜与光照

- 一天 = 12 分钟真实时间，从早上 8 点开始。
- 太阳角度、天空颜色、雾浓度随时间连续变化。
- 入夜后公共建筑窗户会亮灯，路灯自动点亮，室内灯常亮，玩家自带一圈随身照明。

### 7. 建筑与室内

- 全城 27 栋公共建筑，包括邮局、社区中心、诊所、图书馆、工坊、夜校、记忆馆和新增公寓，都是**可以走进去的 2–4 层建筑**。
- 正门居中，进门走到底就是楼梯；室内有前台、货架、病床、办公桌、公寓家具等程序化内饰。
- 每层都有室内照明，夜里临街窗户会自动亮灯。
- 城市覆盖 **6×6 街区**，每个街区有公共地点或住宅；新增三处公园、三家可租店铺。部分公共建筑门口首次探索奖励 $75，重复访问不重复发钱。

### 8. 存档、声音和运行验证

- 正常启动自动读取最近的有效存档；每 60 秒自动保存，暂停菜单支持保存、读取、保存并退出，关闭窗口也会保存。
- 存档为 `user://saves/city.save`，保留 `.bak`，校验失败时尝试恢复备份；双方都损坏时不清空当前游戏。位置、资金、职业、租约、房产家具、车辆改装与停放位置、武器弹匣、任务阶段和探索记录都保存。
- 已加入原创合成的脚步、开火、换弹、车辆引擎、喇叭、城市背景及 UI 提示音。没有新增外部商用素材。
- 缺少可选建筑/角色素材包时使用原创低模外墙与带动画的人物替代，保持 MultiMesh 合批，完整克隆即可运行。
- 自动化入口：`./tools/test.ps1`；详细记录见 [开发与验证](docs/DEVELOPMENT.md)，素材来源见 [素材说明](docs/ASSET_SOURCES.md)。
- 完整交付与剩余限制见 [交付记录](docs/DELIVERY.md)，原始性能数据见 [性能实测](docs/PERFORMANCE.md)。

## 技术说明

- **引擎：** Godot 4.7.2（Forward+ 渲染）
- **语言：** GDScript
- **城市：** 6×6 街区程序化生成，街区 44m、道路 14m，全城约 362×362 米
- **建筑外观：** Quaternius Downtown City MegaKit（CC0）模块拼装，墙/窗/门/檐口用 MultiMesh 合批
- **室内：** 程序化楼板 + 并排折返楼梯 + InteriorFurnish 家具；夜里窗户用发光面片模拟亮灯
- **NPC：** Quaternius 人形角色（CC0，52 套服装），自带 Idle / Walk / Run / Death 等 17 个动画；按速度切换待机/走路/跑步，通缉犯跑步逃窜、伤员倒地
- **动物：** 公园里有静态动物装饰（Lo Polly animals FREE，纯模型无动画）
- **载具：** 基于 `CharacterBody3D` 的街机式驾驶（不会翻车、不会卡住）
- **UI：** 全部代码构建，统一主题，中文字体全局注入

```

  core/game.gd              全局状态（经济/时间/任务/房产/车辆）
  core/main.gd              主控（环境/城市/玩家/UI/装修/营业）
  core/world_builder.gd     程序化城市生成
  player/player.gd          第一人称控制器
  systems/interactable.gd   通用交互体
  systems/npc.gd            行人 / 通缉犯 / 伤员 / 顾客
  systems/vehicle.gd        载具
  systems/mission_target.gd 任务目标（光圈/火焰/伤员/据点）
  ui/hud.gd                 抬头显示
  ui/tablet.gd              平板电脑 8 页
```

### 调试参数

游戏支持命令行调试（`--` 之后传参）：

```bash
SimLife.exe -- --shot=D:/out.png --delay=4        # 4 秒后截图并退出
SimLife.exe -- --at=87,-65,0                       # 传送到指定 x,z,朝向
SimLife.exe -- --time=21.5                         # 设定时间
SimLife.exe -- --page=map                          # 启动时打开平板某页
SimLife.exe -- --topview                           # 高空俯视全城
SimLife.exe -- --test=arrest                       # 自动化测试用例
```

## 已知限制 / 后续可做

- 已有存档与音效；尚无配乐和语音。
- NPC 有低模人形外观与走路/跑步/待机动画，但不会对话、没有语音；动物是静态模型，没有动画。
- 警察 NPC 还不会主动追捕高通的玩家（通缉度目前只影响提示与氛围）。
- 建筑内部已可进入；自有房产的装修系统仍然只对自己的房子开放。
