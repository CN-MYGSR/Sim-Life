# Sim Life · 城市人生

一款用 **Godot 4.7.2** 做的第一人称开放城市人生模拟游戏。
灵感来自 Garry's Mod 的 DarkRP 服务器：选职业、赚钱、买房、买车、装修、加入帮派。

程序化生成的城市；建筑外观使用 [Quaternius《Downtown City MegaKit》](https://quaternius.com) 的 CC0 低模模块，室内家具、道路、载具与角色仍全部由代码生成。

---

## 快速开始

**直接玩：** 双击 `build/SimLife.exe`（单文件，约 140 MB，无需安装）。

**用编辑器打开：** 用 Godot 4.7.2 打开本目录的 `project.godot`。

| 按键 | 功能 |

## 玩法

### 1. 平板电脑（Tab）

游戏里所有"菜单"都在玩家随身携带的平板上，共 8 页：

- **城市地图** — 俯视图，标出全部地点、待售房产、任务目标、自己的车和当前位置
- **职业中心** — 申请 / 切换职业
- **任务** — 接取与追踪当前职业的任务
- **房产** — 购买房屋、进入装修
- **店铺** — 租赁餐厅 / 便利店的使用权
- **车辆** — 车行购车、引擎与轮胎改装、喷漆
- **帮派** — 加入帮派、接帮派活
- **档案** — 生涯统计与操作说明

### 2. 职业与赚钱

| 职业 | 赚钱方式 | 备注 |
| --- | --- | --- |
| 警察 | 巡逻打卡、追捕通缉犯 | 在警局门口可查看勤务 |
| 消防员 | 赶往火场，按住 `E` 灭火 | 消防站 |
| 医生 | 前往伤员位置，按住 `E` 急救 | 圣心医院 |
| 厨师 | **租下日落餐厅后**，在门口开门营业 | 需先租店铺 |
| 便利店老板 | **租下便利店后**，在门口开门营业 | 需先租店铺 |
| 帮派成员 | 抢地盘、走私送货、洗劫便利店 | 报酬高，会涨通缉度 |

- 每完成一个任务**立即结算现金**。
- 在职期间每天 0 点还会自动到账一笔日薪。
- 通缉度（0–5）会随时间缓慢衰减，帮派任务会明显提升它。

### 3. 房产与装修

- 5 套可购买房产，价格 $9,800 – $34,000。
- 买下后走到门口按 `B` 进入**装修模式**：左侧是家具目录（12 种），右侧是已摆放列表。
- 家具会放在你正前方，被占用时自动向旁边顺延。回收返还 60% 购价。
- 房子是**中空可进入**的，墙、屋顶、室内灯都是真实几何体。

### 4. 车辆与改装

- 车行有 5 款车：小踏板、家用轿车、厢式货车、越野皮卡、GT 跑车。
- 买车后车会停在**公共停车场**（地图上有标注），走过去按 `E` 上车。
- 平板「车辆」页可以对每辆车升级**引擎**（三阶）和**轮胎/悬挂**（三阶），以及 7 种喷漆。
- 改装会实时影响极速、加速和抓地力。

### 5. 帮派

- 在平板「帮派」页加入毒蛇帮或灰烬会，自动转职为帮派成员。
- 三种帮派任务：**抢占地盘**（驻守 8 秒）、**走私送货**、**洗劫便利店**（通缉度 +2）。

### 6. 昼夜与光照

- 一天 = 12 分钟真实时间，从早上 8 点开始。
- 太阳角度、天空颜色、雾浓度随时间连续变化。
- 入夜后公共建筑窗户会亮灯，路灯自动点亮，室内灯常亮，玩家自带一圈随身照明。

### 7. 建筑与室内

- 市中心 12 栋公共建筑（警局 / 消防站 / 医院 / 餐厅 / 便利店 / 车行 / 银行 / 仓库 / 空置商铺 / 写字楼 / 公寓楼 / 厂房）都是**可以走进去的 2–4 层建筑**。
- 正门居中，进门走到底就是楼梯；室内有前台、货架、病床、办公桌、公寓家具等程序化内饰。
- 每层都有室内照明，夜里临街窗户会自动亮灯。

## 技术说明

- **引擎：** Godot 4.7.2（Forward+ 渲染）
- **语言：** GDScript
- **城市：** 4×4 街区程序化生成，街区 44m、道路 14m，全城约 246×246 米
- **建筑外观：** Quaternius Downtown City MegaKit（CC0）模块拼装，墙/窗/门/檐口用 MultiMesh 合批
- **室内：** 程序化楼板 + 并排折返楼梯 + InteriorFurnish 家具；夜里窗户用发光面片模拟亮灯
- **载具：** 基于 `CharacterBody3D` 的街机式驾驶（不会翻车、不会卡住）
- **UI：** 全部代码构建，统一主题，中文字体全局注入

### 目录结构

```
project.godot
scenes/main.tscn            主场景（只挂一个脚本，其余全部代码生成）
scripts/
  core/data.gd              静态数据表（职业/地点/房产/车辆/家具/任务）
  core/game.gd              全局状态（经济/时间/任务/房产/车辆）
  core/main.gd              主控（环境/城市/玩家/UI/装修/营业）
  core/world_builder.gd     程序化城市生成
  player/player.gd          第一人称控制器
  systems/interactable.gd   通用交互体
  systems/npc.gd            行人 / 通缉犯 / 伤员 / 顾客
  systems/vehicle.gd        载具
  systems/mission_target.gd 任务目标（光圈/火焰/伤员/据点）
  ui/hud.gd                 抬头显示
  ui/tablet.gd              平板电脑 8 页
  ui/map_view.gd            自绘地图
  ui/decorate_ui.gd         装修界面
assets/shaders/building.gdshader   程序化窗户
assets/fonts/NotoSansSC.otf        中文字体
build/SimLife.exe           打包成品
```

### 调试参数

游戏支持命令行调试（`--` 之后传参）：

```bash
SimLife.exe -- --shot=D:/out.png --delay=4        # 4 秒后截图并退出
SimLife.exe -- --at=87,-65,0                       # 传送到指定 x,z,朝向
SimLife.exe -- --time=21.5                         # 设定时间
SimLife.exe -- --page=map                          # 启动时打开平板某页
SimLife.exe -- --topview                           # 高空俯视全城
SimLife.exe -- --test=arrest                       # 自动化测试用例
```

## 已知限制 / 后续可做

- 没有存档系统（退出即重置）。
- 没有音效与音乐。
- NPC 是低模人形，没有五官与语音。
- 警察 NPC 还不会主动追捕高通的玩家（通缉度目前只影响提示与氛围）。
- 建筑内部已可进入；自有房产的装修系统仍然只对自己的房子开放。
