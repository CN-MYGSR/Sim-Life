# Asset provenance

New content added on the `zugsj666` branch:

| Content | Source | License |
| --- | --- | --- |
| Modular fallback facades, frames, windows, rooftop props | Original geometry in `scripts/core/procedural_assets.gd` | Repository Unlicense |
| Fallback people and Idle/Walk/Run/Death animation tracks | Original geometry and keyframes in the same script | Repository Unlicense |

These are generated locally and require no downloads. When the optional Quaternius
packs are present, the original glTF loading path continues to use them.

The upstream checkout excludes `assets/kit`, `assets/chars` and `assets/animals`.
No unverified replacement downloads have been bundled. In particular the absent
animal pack is not treated as having a verified commercial redistribution license.
Existing `assets/weapons` files predate this branch's development work; their
`PolygonMilitary` names alone do not establish redistribution rights. No additional
third-party weapon assets have been added. Verify upstream ownership before a public binary release.
